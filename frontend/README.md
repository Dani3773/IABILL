# Frontend do IABill

Aplicação em React, TypeScript e Vite. A visão geral do projeto e o passo a passo completo estão no [README principal](../README.md).

## Comandos

```bash
npm ci
npm run dev
npm run build
npm run lint
```

## Configuração

A variável `VITE_API_BASE_URL` define o endereço da API. Sem ela, o frontend usa `http://localhost:8080/api/v1`.
